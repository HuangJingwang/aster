# 结构内容

## 接入与工具链路

目标：区分媒体输入、应用控制与业务执行。
节点：客户端、应用接入、Qwen Realtime、输出与播放、工具执行、业务服务。
数据边：客户端→应用→Qwen；Qwen→工具执行→业务服务→工具执行→Qwen；Qwen→输出与播放。
控制边：应用→Qwen（触发响应）。
画面：三列两行，模型音频输出走外侧，调用与回传分开，避免箭头经过业务节点造成误读。

## Qwen 工具时序

目标：定位执行者、调用关联与显式续答。
参与者：应用 / Agent、Qwen Realtime、业务服务。
时间从上到下：response.create；完整工具参数；应用校验；查询；结果；conversation.item.create；response.create；response.audio.delta。
边界：校验通过才查询；拒绝或超时构造对应结果；模型需要工具时重复工具环节。

## 标签与事实边界

精确标签、位置、箭头、条件见各图 prompts/ 文件。无性能数据，无新业务参与者。图省略会话配置与音频输入的逐帧事件；这些在正文已有说明。Tom 图是概念隐喻，不是实现拓扑。
