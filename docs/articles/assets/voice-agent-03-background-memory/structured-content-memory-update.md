# 记忆同步图修订

目的：解释应用保存状态之后，怎样把变化送入前台模型，并记录本轮播报结果。

依据：文章“记录更新后，还要送入下一次模型调用”及“后台完成后，把有效结果交给前台播报”。通用应用设计示意，不把框架能力和 Mina 专有实现混为一体。

布局：linear-progression，竖向 4:5；画风：craft-handmade；语言：中文；后端：内置 imagegen。

关系：用户补充、后台结果是独立更新事件，应用更新任务记录；响应前读取任务记录与对话历史，选择当前版本结果并组装输入；普通请求或 Realtime 更新二选一送入前台；前台回复并播报；输出侧根据播放事件回写交付状态，供之后读取。

保留原图作历史资产，新图替换正文中的第二张图。删除图中的长期偏好与后台材料分类，将图的重点集中在状态写入、读取、模型输入和交付回写。
