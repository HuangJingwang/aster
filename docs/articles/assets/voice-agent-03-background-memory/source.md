# 原文依据摘录

来源：../../voice-agent-03-background-memory.md

## 前后台协作

- **语音前台**接收输入、说明进度，处理追问和控制意图。
- **业务后台**读取资料、调用工具、整理结果，按最新要求继续执行。

关键在于分别记录**执行状态**和**播报状态**。已经发送的写入还可能完成，取消后的收尾也需要核对真实回执。

对于同一件工作，可以使用稳定的请求 ID，再为每次修改增加版本。后台提交下一步操作或交付结果时，都核对版本是否仍有效。

后台通过工具结果、进度消息或 job 回调回传信息。应用据此更新请求记录，前台再读取适合当前回答的部分。

## 记忆与上下文

对话历史：用户原话、助手输出、交付记录与近期摘要。

请求状态：请求 ID、要求版本、阶段、待答问题。

业务记录：转写、资料、提案、持久作业结果。

长期偏好：用户明确要求跨会话采用的习惯。

前台受理时，整理用户原话、相关对话、身份和资料范围，再交给后台。

较长会话可以采用“近期原文 + 较早摘要”。

会议资料和任务提案可能被修改。应用可以在上下文中保存 ID、版本和简短说明，需要细节时重新读取当前内容，并核对访问范围。
