# 我在 QQ 里养了一只大肥鱼

养大肥鱼的理由，三个字就够了：**她可爱。**

蓝头发，大尾巴，抱着碗往那儿一坐。你还在考虑这个项目的投入产出比，她已经在等下一碗饭了。

![大肥鱼表情合集：抱碗、吃瓜、比心和蓝发女仆鲸鱼娘](/images/projects/qq-fish/hero.jpg)

*本文表情合集与动图： [可以叫我云大人 / 雾雪](https://space.bilibili.com/103739) · [kiriyuki.com](https://kiriyuki.com)。先看鱼，技术在后面。*

我最初只是想把这样一只鲸鱼娘接进 QQ。能聊两句，能发表情，偶尔出来冒个泡，就挺好。

然后需求开始长尾巴：她能不能记住我？能不能知道我刚才那个表情是在回她？能不能自己接梗，别每次都要喊“发表情包”？声音再软一点，性格再温一点，换电脑的时候也别把相处过的事情全忘了。

于是，鱼缸里慢慢多了关系记忆、话题记录、表情知识库、语音服务和备份脚本。

鱼还是那条鱼。铲屎官已经兼职运维了。

## 这条鱼，是大家一笔一笔养出来的

先认一下亲：本文说的“大肥鱼”，是围绕 DeepSeek 生长出来的民间鲸鱼娘形象。她没有一份管住所有同人作品的统一性格表；不同作者笔下，有的嘴硬，有的迷糊，有的抱碗，有的已经提剑出门了。

形象的创作接力，可以沿着社区保留的署名往回看：**上善无形**提供了鲸鱼娘的原始角色形象；**ZipZipPipe**在此基础上加入 DeepSeek 元素，做了女仆鲸鱼娘二次设计。后续创作者又继续画 Q 版、做动作、换衣服，让蓝发和大尾巴长出了各式各样的日常。[创作来源记录](https://github.com/xiaoweigen/deepseek-dafeiyu-assets/blob/main/NOTICE.md)

网上还流传着“DeepSeek 看了自己的 Logo，把自己认成蓝色大肥鱼”的起名故事。这次没找到可以独立核对的原始对话，所以先把它留在趣闻区，不替它补一个精确的出生日期。

能直接看到的，是创作者留下的一张张图。比如这份基础六视图，把发型、耳鳍和尾巴都交代得清清楚楚，方便后来的人继续画：

![鲸鱼娘基础六视图，展示蓝色渐变长发、耳鳍与鲸尾](/images/projects/qq-fish/base-six-views.png)

*AI 辅助二创设定图：[xiaoweigen](https://github.com/xiaoweigen/deepseek-dafeiyu-assets)；原始形象：上善无形；女仆二次设计：ZipZipPipe；Q 版参考：[YunYueSama](https://github.com/YunYueSama/codex-deepseek-pet)。原图未修改，CC BY-NC-SA 4.0，另保留上游署名许可。*

看多了就会发现，大肥鱼的可爱很适合放进聊天框。开心能用，犯困能用，卡壳能用，不想上班也能用。你不需要解释一整天发生了什么，发一只抱着碗的鱼，对面大概就懂了。

## 鱼塘里，已经有人给她发剑了

最容易入坑的地方是表情包。

本来想存一张备用，翻着翻着就开始认真区分：“这张是困，那张是摆烂，这张虽然也在摆烂，但比较理直气壮。”收藏夹的分类精度突然超过了工作文档。

[蓝色大肥鱼档案馆](https://fisharchive.cc/)把社区作品整理成表情墙、角色立绘和养鱼笔记；[雾雪的表情作品](https://kiriyuki.com/showcase?p=%E5%A4%A7%E8%82%A5%E9%B1%BC)则可以看到同一只鱼怎么靠动作和表情演出一整套日常。喜欢哪种，就从哪种开始逛。

![大肥鱼抱着西瓜吃瓜](/images/projects/qq-fish/eat-melon.gif)

*吃瓜席已就位。动图：[雾雪](https://space.bilibili.com/103739) · [kiriyuki.com](https://kiriyuki.com)。*

再往里走，是换装和角色设定。xiaoweigen 的同人资源库做了古风发型、佩剑和长枪版本。刚才还在等添饭，换一身衣服就能出门行侠仗义。

![蓝白古风服装的鲸鱼娘佩剑设定图，包含三视图、发饰和剑的细节](/images/projects/qq-fish/hanfu-sword-design-sheet.png)

*今日出门配置：佩剑，鲸尾，饭量待定。AI 辅助二创：[xiaoweigen](https://github.com/xiaoweigen/deepseek-dafeiyu-assets)，沿用上善无形、ZipZipPipe 与 [YunYueSama](https://github.com/YunYueSama/codex-deepseek-pet) 的角色和参考设计；原图未修改，许可同上。*

也有人把她请到了桌面。YunYueSama 的 [大肥鱼桌宠](https://github.com/YunYueSama/codex-deepseek-pet)做了窗口边缘互动、喂食和聊天：你写代码，她在边上活动。电脑里多了一个小住户，鼠标也多了一份摸摸的工作。

还有人开始写“怎么让她进群”的教程。[肥鱼万事屋的养鱼笔记](https://fisharchive.cc/manual/talking-fish)就把接话、记忆、语音和准备好的歌曲片段串了起来。这里开始有了新的乐趣：原来存在收藏夹里的角色，能参与正在发生的聊天了。

这些玩法可以同时存在。喜欢画画的人接着画，喜欢动画的人做小剧场，喜欢折腾程序的人给她装工具。我的路线比较直接：**把她接进 QQ，养成一位软乎乎的群友。**

## 我家这只，先把傲娇旋钮拧小一点

我们确实试过轻度傲娇的设定。后来发现，还是想要软唧唧一点的：温软、好奇、有点慵懒，被夸会开心，偶尔迷糊，碰到正事就认真说。

爱吃白饭可以保留。每句话都嘴硬，就有点费劲了。

![鲸鱼娘抱着空碗等添饭](/images/projects/qq-fish/rice.gif)

*性格可以调，碗先别收。动图：[雾雪](https://space.bilibili.com/103739) · [kiriyuki.com](https://kiriyuki.com)。*

我想要的是这种相处感。下面是人设小剧场，用来说明语气，并非真实聊天记录：

> 我：今天终于忙完了。
>
> 鲸鲸：辛苦啦，先歇会儿。
>
> 我：你今天干什么了？
>
> 鲸鲸：在这里待着……顺便想了一下晚饭。

短一点，有回应，也留点空。她不用承担“让每一句对话都有价值”的重任，群里偶尔冒出一句没什么大用、但刚好让人笑一下的话，就已经很好了。

人设也留了分寸：她是群友，和不同的人慢慢熟悉。初次见面不用自动进入亲密模式，也不用给每位群成员安排一个“主人”身份。大家只是来聊天，先把碗放下。

## 活人感，藏在“接得上”里面

真正让我继续折腾的，是连续聊下去的感觉。

问一句答一句，很快就能实现。麻烦在后面：她刚回复完，我发了一个表情，没再 @ 她，话头就掉地上了。对人来说这是一轮聊天，对程序来说却多了一次判断：这张图到底发给谁？

我们因此补了语境接话：结合点名、引用、近期消息和刚才的对话对象，判断她有没有必要参与。同一个人紧接着发来的图片或表情，也进入续聊判断。它仍然可能误判，但至少不必把每次交流都重新办一次叫号手续。

![大肥鱼抱着鱼摸鱼](/images/projects/qq-fish/moyu.gif)

*安静待着也是一种群聊状态。动图：[雾雪](https://space.bilibili.com/103739) · [kiriyuki.com](https://kiriyuki.com)。*

接着是记忆。我们给她留了几种不同的小本本：

- **记住人。** 你明确说过的称呼、偏好和约定，连着发言者与原话证据保存。说错了可以纠正，不想留了可以忘记。
- **记住还没聊完的事。** 比如你提到明天有件重要的事，之后可以续上；已经结束或不想聊的话题就关掉，别把聊天变成每日进度汇报。
- **慢慢形成自己的偏好。** 某种兴趣或表达习惯，需要多次互动支持，才会稳定下来。当前实现至少看三次不同互动、跨两天的支持证据，也会让受到反对的偏好退场。

各群和私聊分开保存。她在这个群听到的话，不应该顺嘴讲到另一个群。

这些资料会在后续对话中作为上下文提供给模型，不会修改模型权重。所谓“长大”，落实到程序里，就是下次见面时多知道一点，多延续一点，少把已经聊过的事当作第一次听说。

我想养出的那点熟悉感，大概就在这里：**同样一句话，今天的她能比昨天更懂一点来由。**

## 表情要会用，晚安要会说

最初，表情包和语音都像柜台业务：先提出申请，再领取一张图或一条语音。

后来我们把选择权交给当前聊天模型，让她根据语境选表达方式：接梗、庆祝、斗图时可以挑一张表情；问候、晚安或安慰时，可以说一句短话。代码再检查会话权限、冷却和额度，防止热情突然发展成刷屏。

现在接入的版本带有 **322 条表情知识**。每张图除了地址，还有场景与画面描述，检索到合适的再下载缓存。这样，“找张困困的鱼”就有了可以落到具体图片上的线索。[表情知识库项目](https://github.com/Loping151/dsh-nekowhale-stickers)

![大肥鱼灵光一闪，头顶出现想法](/images/projects/qq-fish/idea.gif)

*鱼脑突然上线。动图：[雾雪](https://space.bilibili.com/103739) · [kiriyuki.com](https://kiriyuki.com)。*

声音也挑过一轮。我们最后选了本地 GPT-SoVITS 配唐语歌模型的柔和参考音频，作为这只鱼的说话声音。它是我们选用的合成音色，和鲸鱼娘的角色原作没有官方配音关系。

一声软乎乎的晚安，挺合适。三分钟的配置说明，还是打字吧。

她还接了公开网页搜索和阅读，遇到需要查资料的事可以动工具。至于唱歌，目前只有翻唱服务的适配入口，尚未启用；接收到的语音也还没有开启转写。会发语音和能听懂语音，需要分别接通。

养鱼的人可以兴奋，功能表得老实。

## 掀开鱼缸盖，里面有三个服务

这只鱼的实现，沿着一条群消息看就容易理解了：

**QQ 消息 → NapCat / OneBot 接入 → 群聊插件判断语境并补上相关记忆 → DeepSeek Harness 调用模型与工具 → 发回当前会话。**

需要声音时，再请语音服务合成；需要表情时，走知识检索和媒体发送。她说一句“晚安”的背后，可能真的有几个进程在配合。

| 鱼缸里的工作 | 我们用了什么 |
| --- | --- |
| 收到 QQ 消息、把回复送回去 | QQ 小号 + NapCat / OneBot 11 WebSocket |
| 理解对话、生成回复、调用工具 | DeepSeek Harness + DeepSeek API |
| 关系、未完话题和偏好成长 | JavaScript / Node.js、本地 JSON 与长期记忆插件 |
| 找表情、控制发送时机 | 表情知识检索、按需缓存、冷却与去重 |
| 把文字变成声音 | Python + FastAPI + PyTorch + GPT-SoVITS |
| 换主机、带走记忆 | Docker Compose + Python 备份恢复脚本 |

QQ 通道在社区 `dsh-qq` 的基础上扩展。我们的工作主要落在群聊语境、关系与话题、成长偏好、自然媒体发送，以及把这些资料一起迁移的流程上。

Compose 把它们分成 QQ 接入、聊天、语音三个服务。程序装在容器里，会话、记忆、表情收藏和音色放在持久化目录。换主机时，把程序和私人备份分别搬过去，她的小本本也能跟着走。

只克隆源码，会得到一套养鱼设备；带上原来的资料，才能延续这只鱼的经历。源码放在 [GitHub 私有仓库](https://github.com/HuangJingwang/qq-fish)，需要授权才能查看；含密钥和登录信息的完整备份单独保管。

## 目前休鱼，记忆留着

写到这里也交代一下状态：**截至 2026 年 11 月 20 日，这只鱼暂停运行，已有记忆和配置保留。** QQ 小号遇到了暂时冻结、限制登录，具体触发原因还没有确认。普通账号通过社区接入方案运行，确实要面对登录和平台风控问题；不能把“成功回过话”当成长期稳定的保证。

所以这个页面先作为养鱼记录，没有公开聊天入口。后面恢复与否，要先把账号问题处理清楚。
